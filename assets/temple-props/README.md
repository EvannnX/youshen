# 神殿原型资产交接

## 当前发布版本

2026-09-23：神像和构件已切回原始网格与原始贴图，不再使用下文旧版轻量副本。四个需要修正骨架坐标的角色从 `assets/temple-fullres/` 加载，顶点和嵌入贴图与源文件完全一致。小太子当前只展示原始 T pose 外形：其导出文件虽有 54 根骨骼，但没有有效手臂蒙皮权重，等待重新导出后再启用垂臂。小太子和孩儿弟高度为标准神像的 2/3。界面使用纯文字，装饰物已配置吊杆或支架。

以下压缩流程为早期实验记录，不代表当前网页资源路径。

入口：`temple-space.html`。资产下载页：`temple-assets.html`。

在项目根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，打开 `http://127.0.0.1:8765/temple-space.html`。ES 模块和 GLB 加载需要 HTTP，不能直接双击 HTML。

五类构件已使用交付的真实 GLB 替换占位件。21 个角色使用 `assets/temple-models/` 下的轻量展示副本，依次加载后保留在展厅，图片仅作加载及失败占位。副本经过网格简化与 1024 像素 WebP 贴图压缩；原始文件保留不变。低端设备仍需实机评估显存与帧率。

12 个角色具有骨骼，使用 `temple-pose.js` 设置垂臂站姿，保留适量腋下间隙和轻微屈肘。其余静态扫描及坐像保留原姿态。五个异常导出的角色在展示副本中重建了手臂权重和骨架坐标，这属于展厅静态站姿修复，不等于完成全身动作捕捉的精细蒙皮。七爷使用已有的动作版骨架生成副本。

## Tripo 资产交付

| 配置键 | 图片 | 建议 GLB 名称 | 场景目标高度 |
| --- | --- | --- | --- |
| lantern | 01-lantern.png | lantern.glb | 1.3 米 |
| banner | 02-banner.png | banner.glb | 3.2 米 |
| curtain | 03-curtain.png | curtain.glb | 3.3 米 |
| plinth | 04-plinth.png | plinth.glb | 0.7 米 |
| lattice | 05-lattice.png | lattice.glb | 3.8 米 |

每类只需一个静态 GLB，无需骨骼。纹理应嵌入 GLB，正面朝 +Z，Y 轴向上。图片是设计参考，不保证比例；薄布需要厚度，格栅孔洞需检查是否堵塞。灯的发光强度需要在网站里按实物模型材质另行调整。

交付原件保存于 `source/`，并备份到桌面 `游神素材/神殿场景模型/`。根目录 `temple-props.js` 已配置五类展示 GLB。加载器按高度缩放、居中和落地，建筑构件另按配置匹配宽深尺寸，所有同类占位实例自动替换；失败时保留占位。可用 `rotationY` 调整朝向。帷幔置于主坛后方，避免遮挡群像。

`tools/prepare-temple-models.mjs` 可重新生成展示副本，`assets/temple-models/manifest.json` 记录来源、面数、体积及修复情况。`tools/check-temple-poses.mjs` 校验骨骼方向、臂长和修复模型的手部顶点下降。

## 场景与操作

中央通道可行走；左右展位按策展顺序排列，五福大帝位于末端主坛。这不是当地仪式队序的复原。拖动环顾，WASD 或方向键移动；手机有方向按钮。索引和上一个、下一个按钮可直接前往角色。详情内可旋转神像，加载失败可重试。三维不可用时可以切回图文神殿。

使用本地固定版本 Three.js 0.170.0，附 MIT 许可。GLTFLoader、DRACOLoader 和解码器均本地加载。当前没有实现动作捕捉或音频自动播放。

生成工具：内置 image_gen。完整五条提示词见 `prompts.json`。图像为孤立资产、灰底、红黑旧金配色，专供模型重建。
